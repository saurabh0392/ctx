Your context bill

Every tool result your agent reads spends context. This is the bill, itemized from your own sessions: the biggest sinks first, how much ctx could safely reclaim, and how much it already has. No proof needed to see it, it is just your data.

Compaction health

Compaction is your agent hitting its context limit: it summarizes and drops older detail so it can keep going, and the detail it drops is gone for the rest of the session. That is the platform's call, not ctx's. This page reads how often it happens on your work and what you can do to need it less often.

Tool report

A plain-language read on what ctx is doing with each tool on your machine. The story comes first; the numbers sit underneath when you want to dig in. Nothing here is a guess. Every verdict comes from your own sessions.

Every agent, one honest layer

ctx sits under each coding agent you run and treats them as one. No agent vendor measures the others, so this is the one place you see Claude Code and Cursor side by side, on your own work. Each card is that agent's real activity. Where ctx hasn't seen an agent yet, it says so plainly instead of showing a zero.

Activity

The most recent tool results ctx looked at, tool by tool. This is the running record behind every decision. Watching means nothing changed. Trimmed means a tool that earned it; the tool still ran in full, ctx only shortened what the agent read back.
