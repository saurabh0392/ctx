Data stays on this machine. Tune privacy, budget, and profile in a few steps.

ctx stores metrics under ~/.ctx. No telemetry is sent out. Anthropic API traffic is unchanged except MCP tool lists are trimmed before the model sees them.

  • Stored: token counts, cost estimates, optional truncated prompt text, MCP tool usage, optional embeddings.
  • Not stored here: API keys, full raw logs (only what ingest copies).
  • Dashboard loads Chart.js from a CDN; no session data is sent there.
